Dependent Texture Read

6/7

Dependent Texture Read — ситуация, когда чтение
данных из текстуры выполняется не по тем
текстурным координатам, которые были
переданы во фрагментный шейдер
Это не позволяет драйверу видеокарты
оптимизировать пересылку данных между
различными областями памяти
По возможности следует избегать
трансформации текстурных
координат во фрагментном шейдере

MAD-инструкции

Вычисления вида A * B + C
выполняются GPU за один такт

result = (0.5 * alpha) + 0.5;
лучше, чем
result = (alpha + 1.0) / 2.0;
result = (alpha + 1.0) * 0.5;
result = (alpha / 2.0) + 0.5;
